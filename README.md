# OMNIRO VPN — Telegram-бот с интеграцией H1 Panel

Проект содержит обычное Telegram-меню, покупку подписки, профиль, поддержку, админ-раздел и интеграцию платежей RollyPay. Mini App удалён.

## Настройка на Sever_host
1. Загрузите архив и распакуйте его. Главный файл: `main.py`.
2. В `.env` или переменных окружения укажите НОВЫЙ `BOT_TOKEN`, `ADMIN_ID`, `ROLLYPAY_API_KEY`, `ROLLYPAY_SIGNING_SECRET`. Ранее опубликованные секреты нужно перевыпустить.
3. Укажите настоящий публичный HTTPS-домен в `PUBLIC_BASE_URL`, например `https://ваш-домен`. Не оставляйте `YOUR-HOST-DOMAIN`.
4. В панели RollyPay задайте Callback URL: `https://ваш-домен/payments/callback`. Хостинг должен проксировать HTTPS на порт приложения `8080`.
5. Запуск: `python main.py`.

## Важно
- В архиве `TEST_MODE=false`: реальные платежи не заработают, пока не настроены домен и callback.
- Логи вида `Bot is running` и `Start polling` подтверждают запуск Telegram-бота, но не успешную работу платежей.
- Выдача реальных VPN-конфигураций не подключена: для этого требуется API/доступ к вашему VPN-серверу. После оплаты бот пока не сможет сам создать настоящий VPN-ключ без этой интеграции.
- Если Sever_host не предоставляет публичный HTTPS-домен или проксирование порта 8080, для webhook понадобится другой публичный HTTPS endpoint.


## Подключение H1 Panel API

В Render → Environment добавьте `H1CLOUD_API_BASE=https://s-25154.pl7.h1clayd.click/api`, `H1CLOUD_API_TOKEN` (создайте новый токен панели, старый уже опубликован) и при необходимости `H1CLOUD_DEVICE_LIMIT=3`. Токен не добавляйте в код или GitHub. Клиент H1 создаётся после подтверждённой оплаты; ссылка подписки сохраняется в подключении. Убедитесь, что тарифы и доступные инбаунды настроены в панели.
